# Differential Equations Notes

Key formulas:

- Separable equation: `dy/dx = f(x)g(y)`
- Solution pattern: `Integral dy / g(y) = Integral f(x) dx + C`
- Linear first-order equation: `dy/dx + P(x)y = Q(x)`
- Integrating factor: `IF = e^(Integral P(x) dx)`

JEE concept:

Classify the differential equation before manipulating it. For linear equations, multiply every term by the integrating factor.

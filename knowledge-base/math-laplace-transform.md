# Laplace Transform Notes

Key formulas:

- `L{f(t)} = Integral_0^infinity e^(-st) f(t) dt`
- `L{1} = 1/s`
- `L{t^n} = n! / s^(n+1)`
- `L{f'(t)} = sF(s) - f(0)`

JEE concept:

Laplace transform questions usually reduce differential equations to algebraic equations in `s`, then use inverse transforms.

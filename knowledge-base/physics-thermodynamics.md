# Thermodynamics Notes

Key formulas:

- First law: `Delta U = Q - W`
- Isothermal ideal gas work: `W = nRT ln(V2 / V1)`
- Adiabatic relation: `PV^gamma = constant`
- Heat engine efficiency: `eta = 1 - T_c / T_h`

JEE concept:

Always establish the sign convention before solving. For cyclic processes, `Delta U = 0`, so net heat equals net work.
